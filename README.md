macOS-приложение для анализа рисков информационной безопасности предприятия. Позволяет вести реестр ИТ-активов, рассчитывать ожидаемый ущерб и формировать отчёты.

## Возможности

- **Реестр активов** — добавление, редактирование, удаление и копирование ИТ-активов
- **Оценка рисков** — расчёт на основе вероятности, тяжести и диапазона ущерба
- **Классификация** — автоматическая маркировка уровня риска цветом
- **Экспорт отчётов** — CSV, TXT, JSON
- **Сохранение данных** — сериализация в JSON для повторного использования
- **Статистика** — суммарный ожидаемый ущерб по всем активам

## Системные требования

- macOS 12.0 (Monterey) или новее
- Xcode 14.0+
- Swift 5.7+

## Установка и запуск

### Через Xcode

1. Клонируй репозиторий:
   ```bash
   git clone https://github.com/ВАШ_НИК/RiskAnalyzer.git
   cd RiskAnalyzer
   ```

2. Открой проект:
   ```bash
   open RiskAnalyzer.xcodeproj
   ```

3. Выбери целевое устройство **My Mac** и нажми **Cmd + R** (или *Product → Run*).

### Важно: Sandbox

Приложение использует `NSSavePanel` для сохранения файлов. Убедись, что в **Signing & Capabilities** включено:

```
App Sandbox → User Selected File: Read/Write
```

## Уровни риска

| Значение | Уровень | Цвет |
|----------|---------|------|
| ≥ 8.0 | **КРИТИЧЕСКИЙ** | 🔴 Красный |
| 6.0 – 7.9 | **ВЫСОКИЙ** | 🟠 Оранжевый |
| 4.0 – 5.9 | **СРЕДНИЙ** | 🟡 Жёлтый |
| 2.0 – 3.9 | **НИЗКИЙ** | 🟢 Зелёный |
| < 2.0 | **МИНИМАЛЬНЫЙ** | 🔵 Синий |

## Формулы расчёта

```
Ожидаемый ущерб = Вероятность × (Мин. ущерб + Макс. ущерб) / 2
Уровень риска   = Вероятность × Тяжесть
```

## Экспорт данных

Приложение поддерживает три формата отчётов:

- **CSV** — для импорта в Excel / Google Таблицы
- **TXT** — человекочитаемый отчёт с датой
- **JSON** — машиночитаемый формат для интеграций
